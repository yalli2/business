# The Business Book — Interactive Study Site

Interactive study site for an international-school Business class, based on *The Business Book* (DK, “Big Ideas Simply Explained”).

- **6 chapters · 98 topics · 980 practice questions**
- Each topic: summary, key points, key terms, key people, case study, discussion question, flashcards
- Practice quiz per topic (multiple choice, true/false, fill-in-the-blank) with instant scoring and explanations
- Chapter test (all questions of a chapter) with results by topic
- Progress and best scores saved in the browser
- Language button (top right): English / 한국어

Hosted with GitHub Pages — open `index.html`.
